# 💰 Banking System in Java – Console Application

This project is a **console-based banking system** developed using Java and core OOP concepts. It allows users to create accounts, deposit and withdraw money, and check their balances. Customer data is stored using Collections, and file handling ensures data persistence even after the application is closed.

---

## ✨ Features

- **Create Account** – Register new users with unique account details.  
- **Deposit Money** – Add funds with real-time balance updates.  
- **Withdraw Money** – Validates amount to prevent invalid or unsafe transactions.  
- **Check Balance** – Instantly view the current account balance.  
- **File Handling** – Automatically saves and loads customer data using Java I/O.

---

## 🛠 Technologies & Concepts Used

- **Object-Oriented Programming (OOP)**  
- **Collections Framework (HashMap)** to store customer details efficiently  
- **Exception Handling** for invalid input and transactions  
- **File Handling** for long-term data storage
