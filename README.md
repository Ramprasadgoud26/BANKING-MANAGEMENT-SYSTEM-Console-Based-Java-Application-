💰 Banking System in Java – Console Application

This project is a console-based banking system developed in Java using core Object-Oriented Programming principles. It allows users to perform essential banking operations in a simple and interactive way while ensuring data integrity, error handling, and persistent storage.

✨ Features

Create New Account
Users can register by providing basic details. Each account is uniquely identified for future transactions.

Deposit Money
Add funds securely with real-time balance updates.

Withdraw Money
Withdrawal operations include validation to prevent overdrafts or invalid inputs.

Check Account Balance
Users can instantly view their current balance.

Persistent Data Storage
All customer data is saved using file handling, so information remains available even after restarting the application.

🛠️ Technologies & Concepts Used

Object-Oriented Programming (OOP)
Implemented using classes, objects, constructors, methods, and encapsulation.

Collections Framework (HashMap)
Efficiently stores and retrieves customer account data.

Exception Handling
Gracefully handles invalid transactions and user input errors.

File Handling (Java I/O)
Reads and writes user account details to a file for long-term storage.

▶️ How to Run

Install Java (JDK 8 or above).

Clone the repository:

git clone <your-repo-link>


Compile the program:

javac BankingSystem.java


Run the application:

java BankingSystem
